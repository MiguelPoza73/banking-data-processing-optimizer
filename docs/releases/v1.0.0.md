# v1.0.0 — Aplicación de escritorio para Windows

Descarga **BankingOptimizer.exe** en los archivos de esta release y ábrelo con doble clic. No necesitas instalar Python, paquetes ni descomprimir un ZIP. Compatible con Windows x64.

## Incluye

- Generación reproducible de transacciones sintéticas en EUR.
- Procesamiento secuencial y paralelo con dos y cuatro trabajadores.
- Comparación de resultados completos entre estrategias.
- Mediciones de tiempo, rendimiento, speedup, mejora temporal y memoria RSS observada.
- Exportación CSV y gráficos PNG.

Empieza con 100 transacciones, 3 repeticiones y lote 25. El arranque del ejecutable único puede tardar mientras extrae sus dependencias temporales.

Las mediciones del repositorio proceden de la ejecución desde Python. El empaquetado puede cambiar los costes de arranque y memoria. Esta distribución queda pendiente de validación funcional manual por el autor.
